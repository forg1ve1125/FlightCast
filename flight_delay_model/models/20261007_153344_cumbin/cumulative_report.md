## 方法

4 个链式二分类器 P(>0) / P(>15) / P(>30) / P(>60)，单调投影后逐档相减：

```
bucket0 = 1 - P(>0)      bucket1 = P(>0)  - P(>15)
bucket2 = P(>15) - P(>30)  bucket3 = P(>30) - P(>60)   bucket4 = P(>60)
```
